- Порт 8000 может быть занят забытым uvicorn со старым кодом: проверяй `lsof -iTCP:8000 -sTCP:LISTEN` и время
  запуска процесса. Новый код виден сервису только после перезапуска.
- Retro-venv имеет СТАРЕЕ rdkit (2023.09.6): код `minichem/tools/` (route_check, reaction_types,
  retrosynthesis) должен работать и там (`AIZYNTH_PYTHON=/Users/islambek_sadykov/tools/aizynth/.venv/bin/python`,
  `AIZYNTH_CONFIG=/Users/islambek_sadykov/tools/aizynth/data/config.yml`, `ENABLE_RETROSYNTHESIS=true`).
- Супервизор видит результаты инструментов, обрезанные до `MAX_RESULT_CHARS=1500`: важные поля в начало.
- Gemini: `message.text`, а не `.content`; температура намеренно не задана. Eval и тесты владельца делят одну
  квоту Gemini (free tier): не гонять eval параллельно с владельцем и несколькими агентами.
- Веб-страницы через fetch-инструмент пересказываются малой моделью: версии и пины сверять с установленным пакетом.
- `git clone` с GitHub шёл ~0.2 МБ/с, Zenodo ~150-200 КБ/с: большие загрузки только `curl -C -` с проверкой
  размера и md5 (скачивание REINVENT-приоров заняло ~20 минут).

## Решения владельца (действуют)

1. Уровень: средний продакшн, один человек, одна Mac. "Без облака" УТОЧНЕНО владельцем 2026-11-13: запрещено только
   платное и недоступное владельцу; бесплатный сервис через API или сайт можно (CLAUDE.md, README, roadmap обновлены).
2. Платное, закрытое и недоступное не используем; сначала ищем готовое (MCP/библиотека/бесплатный API), свой код
   только если нет, причину записать, лицензию записывать. Локальную установку тяжёлого компонента обосновывать
   (нет бесплатного сервиса, замер показал медленно или ненадёжно, или приватность).
3. Прецеденты реакций: вариант B (патентные реагенты, растворители, выход, номер патента, год; помечать "из патента,
   текст-майнинг, не проверено"; без LLM-условий).
4. LLM: Gemini остаётся.
5. REINVENT 4: установлен (сделано), RL позже.
6. Стратегия: сильное оставить (handles, ошибки значениями, глубина ретросинтеза, пины, offline-тесты,
   постоянная MCP-сессия), слабое заменять на то, что у AstraZeneca.
7. Тест UI: Playwright на Python в отдельном venv.
8. Не коммитить и не пушить без команды владельца.
