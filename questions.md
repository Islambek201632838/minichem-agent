Ретросинтез (блоки 1 и 5) работает, только если запущено с `ENABLE_RETROSYNTHESIS=true`; поиск на
тяжёлых молекулах занимает 1-2 минуты, число шагов частичных маршрутов плавает.

## 8. Ретросинтез, реакции и прецеденты (реагенты, растворители, выход, патент)

Нужны оба переключателя: `ENABLE_RETROSYNTHESIS=true` и `ENABLE_PRECEDENTS=true` (сервисы подняты с ними, см.
status.md). Ожидается: маршрут как `продукт <- реагенты` по шагам; для шага реагенты и растворители ИЗ ПАТЕНТНОЙ
ЗАПИСИ (списком, без разделения), выход, номер патента, год и пометка "из патентов США, текст-майнинг, не
проверено"; никаких температур, времён и количеств. Проверено вручную: п. 1 (ибупрофен: прецеденты H2SO4 и вода,
патенты 2013-2016); остальные не прогонялись.

1. Маршрут и прецеденты последнего шага (проверено):
```
Найди маршрут ретросинтеза ибупрофена. Для последнего шага маршрута (который даёт ибупрофен) покажи патентные прецеденты: реагенты и растворители, выход, номер патента и год.
```

2. Прецеденты для каждого шага маршрута лекарства среднего размера:
```
Построй ретросинтез лидокаина. Для каждого шага маршрута покажи по два патентных прецедента: реагенты и растворители, выход, патент, год. Отдельно отметь шаги, для которых прецедентов не нашлось.
```

3. Конкретная реакция без ретросинтеза (амин алкилируется хлорацетамидом):
```
Покажи патентные прецеденты для реакции 2-хлор-N-(2,6-диметилфенил)ацетамид + диэтиламин -> лидокаин: какие реагенты и растворители встречаются, какие выходы, из каких патентов?
```

4. Сравнение выходов и растворителей между прецедентами (сульфонамид на последнем шаге силденафила):
```
Построй ретросинтез силденафила и возьми шаг, где образуется сульфонамидная связь с N-метилпиперазином. Покажи три патентных прецедента для него и скажи, какой с самым высоким выходом и какие реагенты и растворители в нём указаны.
```

5. Тяжёлая молекула: частичный маршрут и честный ответ о том, чего нет:
```
Найди маршрут ретросинтеза иматиниба. Если маршрут решён не полностью, скажи, какие вещества не нашлись в наличии. Для шага, который образует амидную связь, покажи патентные прецеденты (реагенты, растворители, выход, патент).
```

6. Условия, которых в данных нет (ожидается: температур, времени и количеств нет, никаких выдуманных значений):
```
Для последнего шага синтеза ибупрофена из нитрила покажи прецеденты и скажи, при какой температуре и сколько часов вести реакцию и в каких количествах брать реагенты.
```
