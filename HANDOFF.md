# Решения владельца

1. **Уровень проекта:** "средний продакшн, не накручивать, качественный, решение, но локальное". Один
   человек, одна машина, без облака. Внесено в README и CLAUDE.md.
2. **Платные, закрытые и недоступные сервисы не используем** (OpenEye, платные облака, всё, до чего у нас нет
   доступа). УТОЧНЕНИЕ (2026-11-12 вечер): это не значит "писать всё самим". Если есть ОТКРЫТЫЙ, доступный
   готовый MCP-сервер (или библиотека) под задачу, используем его, а не пишем с нуля. Порядок: сначала поиск
   готового открытого решения (лицензия, живость, нужен ли ключ), свой код только если готового нет или оно не
   подходит (причину записать). Лицензию новых вещей записывать. Внесено в CLAUDE.md; в README поправить при
   ближайшей правке (там пока старая формулировка "only open or free software").
3. **Прецеденты реакций: вариант B.** Показывать реагенты и растворители из патентной записи, выход,
   номер патента, год; всё, что из базы без проверки, помечать "из патента, текст-майнинг, не проверено".
   Никаких LLM-угаданных условий, количеств, температур (их в данных и нет). Это ОСЛАБЛЯЕТ жёсткое правило
   "синтез-агент не называет растворители": при реализации поправь CLAUDE.md (Hard rules, Safety),
   `prompts/*.md`, README и тесты так, чтобы исключение было только для данных из базы.
4. **LLM: Gemini остаётся** (не переходить на Ollama).
5. **REINVENT 4: установка разрешена и ожидается.** Отдельный venv (`~/tools/reinvent/.venv`), приоры вручную,
   ничего автоматически.
6. **Стратегия:** "наши сильные качества оставь, слабые замени на то, что у AstraZeneca". Сильные у нас: протокол
   handles, ошибки значениями, глубина ретросинтеза, пины зависимостей, offline-тесты, постоянная MCP-сессия.
   Слабые (брать у AZ): генерация аналогов (REINVENT вместо заглушки), прецеденты реакций, размер и сложность
   eval (генератор вопросов, набор этических/граничных вопросов, позже LLM-судья).
7. **Тест UI в браузере: Playwright на Python** (sync API), без TypeScript, в отдельном venv вне проекта
   (`uv venv` в scratchpad, `uv pip install playwright`, `playwright install chromium`, ~150 МБ); в зависимости
   проекта не добавлять без нужды. Авторизации нет, кнопок мало.
8. **Не коммитить и не пушить без команды владельца.** Сейчас НЕ закоммичено ничего из сегодняшнего (см. ниже).

# Ловушки

- macOS: `sed -i` требует суффикс, нет команд `timeout` и `setsid`, `gh` не установлен. В zsh строка `echo ====`
  ломается (`=` раскрывается): используй `echo ----`. Правки лучше делать Edit-ом или коротким python-скриптом.
  Write/Edit падают, если файл изменился после чтения: перечитай.
- Скрипты вне проекта запускай с `PYTHONPATH=.` из корня проекта.
- Порт 8000 может быть занят забытым uvicorn со старым кодом: проверяй `lsof -iTCP:8000 -sTCP:LISTEN` и время
  запуска процесса, прежде чем доверять его ответам. Новый код виден сервису только после перезапуска.
- RDKit SMARTS: незамапленные атомы шаблона УДАЛЯЮТСЯ из продукта. Retro-venv имеет СТАРЕЕ rdkit (2023.09.6):
  код из `minichem/tools/` (route_check, reaction_types, retrosynthesis), который импортирует retro-сервер,
  обязан работать и там (`AIZYNTH_PYTHON=/Users/islambek_sadykov/tools/aizynth/.venv/bin/python`,
  `AIZYNTH_CONFIG=/Users/islambek_sadykov/tools/aizynth/data/config.yml`, `ENABLE_RETROSYNTHESIS=true`).
- Супервизор видит результаты инструментов, обрезанные до `MAX_RESULT_CHARS=1500`: важные поля в начало.
- Поиск ретросинтеза на тяжёлых молекулах 1-2 минуты, число шагов частичных маршрутов плавает.
- Gemini: `message.text`, а не `.content`; температура намеренно не задана.
- Веб-страницы через fetch-инструмент пересказываются малой моделью: версии и пины сверять с установленным пакетом.
- Модель иногда называет числа из памяти вместо результата инструмента (`g019`): это ловят проверки `numbers`.
